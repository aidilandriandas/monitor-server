1. Bridge Link-Layer Filtering (L2): When you or Fail2ban block an IP in Aegis, the engine executes ebtables -A AEGIS_CLUSTER_DROP -p IPv4 --ip-src/dst <IP> -j DROP directly on the Proxmox Hypervisor (10.10.10.9).
